# Выполнение домашнего задания
Проект выполняет функции по маскированию номера счета, маскирование номера платиковой карты.
Выполняет функцию по форматированию даты в формат ДД.ММ.ГГГГ.
Также выполняет функции по фильтрации списка операций по статусу и сортировке списка операций по дате проведения.

## Использование
Клонируйте репозиторий

```typescript
git clone https://github.com/Dragon-Slayer-Bild/Home_work_rep
```
Установите зависимости

```typescript
pip install -r requirements.txt
```
Необходимо ипортировать Union
```typescript
from typing import Union
```
Необходимо ипортировать datetime
```typescript
from datetime import datetime
```

Пример вызова функций в модуле widget.py
```typescript
card_account_number = "Visa Platinum 8990922113665229"
print(mask_account_card(card_account_number))
card_account_number = "Счет 35383033474447895560"

```

Пример вызова функций в модуле processing.py для получения списка операций по статусу ( возможные значения CANCELED,EXECUTED),

## Тестирование
В пакете tests добавлены следующие тесты:

[test_masks.py](tests/test_masks.py)
- Проверка на с корректными данными номера карты/счета на соответветствие длины символов
- Проверка исключения с некоректными даными номера карты/счета 
- Проверка на тип передаваемых данных

[test_processing.py](tests/test_processing.py)
- Проверка на маскированние номера карты с разными типами карты
- Проверка на маскированние номера счета
- Проверка исключения с некоректными данными номера карты/счета 
- Проверка на тип передаваемых данных
- Проверка на корректный формат передаваемой даты
- Проверка исключения на некорректный формат передаваемой даты


[test_widget.py](tests/test_widget.py)
- Проверка на фильтрацию по статусу операции
- Проверка исключения на отсутствие передаваемого статуса
- Проверка на сортировку даты по убыванию/возрастания
- Проверка исключения на корректность передаваемой даты

[test_generators.py](tests/test_generators.py)
- Проверка на корретность списка всех транзакций с выбранной валютой
- Проверка на корректность получения первой транзакции с выбранной валютой из генератора
- Проверка с разными валютами
- Проверка на пустой список транзакций
- Проверка, когда валюта не найдена в списке транзакций
- Проверка на корректность получения описания из генератора
- Проверка если отсутствует ключ 'description', возвращается 'Описание не найдено'
- Проверка что пустой список должен вызывать ValueError
